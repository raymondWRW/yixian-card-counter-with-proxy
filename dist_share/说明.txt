弈仙牌计数器（完整版）
======================

两个始终置顶的悬浮窗：
  - 主窗口    — 显示回合 / 伤害模拟（实时对战或单方模式）
  - 计数器    — 显示牌库中剩余的牌

两个窗口都可通过标题栏拖动、自动调整大小。
拖动窗口右下角可按比例缩放整个界面。


使用方法
--------
1. 将此文件夹解压到任意位置（放在桌面即可）。
2. 双击  YiXianCounter.exe
   （如果 SmartScreen 拦截 “Windows 已保护你的电脑”：
    点击 “更多信息” -> “仍要运行”。）
3. 启动弈仙牌。两个窗口会在几秒内开始显示数据。

就这么简单 —— 无需安装步骤、无需管理员权限、无需安装证书。

计数器直接读取游戏数据（挂接游戏本身，不再使用网络代理）。
首次运行时还会下载一个小的引擎组件（约 42 MB），用于伤害与
复盘功能；该下载需要联网，但只发生一次。卡牌计数本身无需联网。


遇到问题怎么办
--------------
程序会在界面上直接提示问题所在：

  - 启动时弹出 “缺少运行库 / Missing runtime”：
      未安装 Microsoft Edge WebView2 运行时（绘制窗口所必需）。
      Win11 已自带；Win10 请从下方免费下载安装：
        https://developer.microsoft.com/microsoft-edge/webview2/
      安装后（约 30 秒，无需重启）重新运行 YiXianCounter.exe。

  - 红色横幅 “找不到游戏 / Game not found”：
      弈仙牌未运行，且未在默认 Steam 路径找到
      （C:\Program Files (x86)\Steam\steamapps\common\YiXianPai\）。
      直接启动游戏即可，计数器会自动识别。若游戏安装在其它位置，
      请把环境变量 YX_GAME_EXE 设为 YiXianPai.exe 的完整路径。

  - 红色横幅 “无法挂接游戏 / Can't hook game”：
      杀毒软件 / Windows Defender 拦截了程序读取游戏。
      请把本文件夹加入杀毒白名单后重新运行。

  - 橙色横幅 “引擎下载失败 / Engine download failed”：
      无网络，或无法访问 gitee.com。卡牌计数仍可正常使用；
      伤害与复盘功能需要这一次性下载，联网后重试即可。

  - 蓝色横幅 “正在连接游戏… / Connecting…”：
      正常提示 —— 进入对局后会自动消失。

  - 伤害面板显示 “未识别卡片 (灵羽)”：
      棋盘上的 灵羽 找不到可合的 1 级 灵气/身法 牌，模拟器无法
      预测合并数值。放一张 1 级 灵气或身法牌上棋盘即可恢复。


对局日志（用于反馈问题 + 复盘功能）
----------------------------------
每局游戏都会在  battle_log\<年-月-日_时分秒>\  下生成一个文件夹，
内含：
  msgdump.jsonl       — 解码后的全部 WebSocket 帧
  shadow_log.txt      — 可读的游戏状态日志
  deck_tracker.jsonl  — UI 看到的每一帧状态
  battle_log.json     — 游戏自身 BattleLog.json 的拷贝（每回合 HP）

如果发现 bug，把  battle_log\  下最新一局的文件夹打包发回即可。
日志写在 .exe 同目录下，想清空时直接删除  battle_log\  即可。

启动错误 / 引擎同步等诊断日志另存于：
  %LOCALAPPDATA%\YiXianCounter\app.log
  %LOCALAPPDATA%\YiXianCounter\oracle-sync.log


自动更新
--------
每次启动时程序会向 Gitee 检查新版本。如有新版会在主窗口顶部
弹出 “有新版本” 横幅，点 “更新” 即可下载、校验（SHA256）、自动
替换。无需访问 GitHub，使用 gitee.com，从中国大陆可正常访问。

更新仅提示，不会静默执行。可点 X 暂时忽略。


系统要求
--------
- Windows 10 或 11，64 位。
- Microsoft Edge WebView2 运行时（Win11 已自带；免费下载：
  https://developer.microsoft.com/microsoft-edge/webview2/ ）
- 首次启动需联网（用于一次性下载引擎组件）。


卸载
----
直接删除本文件夹即可。如需同时清除缓存的引擎和日志：
  删除  %LOCALAPPDATA%\YiXianCounter\
