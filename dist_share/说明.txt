弈仙牌计数器（完整版）
======================

两个始终置顶的悬浮窗：
  - 主窗口    — 显示回合 / 伤害模拟（实时对战或单方模式）
  - 计数器    — 显示牌库中剩余的牌

两个窗口都可通过标题栏拖动、自动调整大小。
拖动窗口右下角可按比例缩放整个界面。


首次安装  （仅需操作一次）
--------------------------
1. 将此文件夹解压到任意位置（放在桌面即可）。
2. 双击  Setup.bat
3. 在用户账户控制（UAC）弹窗中点击“是”。
4. 等待出现 "Setup complete!" 后按任意键关闭窗口。

如果 SmartScreen 拦截了程序（"Windows 已保护你的电脑"）：
  - 点击 "更多信息" -> "仍要运行"。


日常使用
--------
1. 双击  Run.bat
2. 在 UAC 弹窗中点击"是"。
3. 启动弈仙牌。两个窗口会在几秒内开始显示数据。

程序必须以管理员权限运行，因为代理需要在内核层级
拦截网络流量（WinDivert 驱动）。


对局日志（用于反馈问题 + 未来的对局回放功能）
--------------------------------------------
每局游戏都会在  battle_log\<年-月-日_时分秒>\  下生成一个文件夹，
内含：
  msgdump.jsonl       — 解码后的全部 WebSocket 帧
  shadow_log.txt      — 可读的游戏状态日志
  deck_tracker.jsonl  — UI 看到的每一帧状态
  battle_log.json     — 游戏自身 BattleLog.json 的拷贝（每回合 HP）

如果发现 bug，把  battle_log\  下最新一局的文件夹打包发回即可。

日志写在 .exe 同目录下。想清空时直接删除  battle_log\  即可。


自动更新
--------
每次启动时程序会向 Gitee 检查新版本。如有新版会在主窗口顶部
弹出 “有新版本” 横幅，点 “更新” 即可下载、校验（SHA256）、自动
替换。无需访问 GitHub，使用 gitee.com，从中国大陆可正常访问。

更新仅提示，不会静默执行。可点 X 暂时忽略。


系统要求
--------
- Windows 10 或 11，64 位。
- Microsoft Edge WebView2 运行时（Win11 已自带；免费下载：
  https://developer.microsoft.com/microsoft-edge/webview2/ ）


隐私提示  （请阅读）
--------------------
Setup.bat 会将 mitmproxy 的根证书（CA）安装到 Windows 受信任根
存储区，这是代理解密游戏 HTTPS WebSocket 流量所必需的。

代理运行期间，持有此 CA 私钥的程序可以拦截你的其他 HTTPS 流量。
该私钥保存在  %USERPROFILE%\.mitmproxy\  目录中，由本机生成，
不会被发送给任何人。

只从你信任的人那里安装这类软件。


卸载
----
1. 移除受信任的 CA：
   certutil -delstore Root mitmproxy
2. 移除 Defender 排除项（以管理员身份运行 PowerShell）：
   Remove-MpPreference -ExclusionPath "<本文件夹路径>"
3. 删除本文件夹。
4. 如需彻底清除证书文件，可删除  %USERPROFILE%\.mitmproxy\


问题排查
--------
- 窗口能打开但数据不更新：
    代理未生效。常见原因：
      a) 未以管理员身份启动 - 请用 Run.bat。
      b) 证书未被信任 - 重新运行 Setup.bat。
      c) 杀软拦截了 WinDivert - 添加排除项或临时关闭实时防护。

- 启动时报错 "Windows 无法访问指定的设备"：
    Defender 删除了 .exe。从隔离区还原，并重新运行 Setup.bat
    （排除项步骤可防止再次发生）。

- 安装后游戏一直无法进入对局：
    证书信任可能配置错误。重新运行 Setup.bat。仍然失败的话，
    先卸载（见上）再重新安装。

- 伤害面板显示 "未识别卡片 (灵羽)"：
    棋盘上的 灵羽 (lv2/3) 找不到可合的 1 级 灵气/身法 牌。模拟器
    无法预测合并后的真实数值，所以拒绝出结果。把一张 1 级
    灵气或身法牌放上棋盘，模拟器就会重新工作。
