弈仙牌计数器（精简版）
======================

一个小型悬浮窗，显示弈仙牌牌库中剩余的牌。
窗口始终置顶，可通过标题栏拖动，自动根据卡牌数量调整大小。


首次安装  （仅需操作一次）
--------------------------
1. 将此文件夹解压到任意位置（放在桌面即可）。
2. 双击  Setup.bat
3. 在用户账户控制（UAC）弹窗中点击"是"。
4. 等待出现 "Setup complete!" 后按任意键关闭窗口。

如果 SmartScreen 拦截了程序（"Windows 已保护你的电脑"）：
  - 点击 "更多信息" -> "仍要运行"。


日常使用
--------
1. 双击  Run.bat
2. 在 UAC 弹窗中点击"是"。
3. 启动弈仙牌。计数器会在几秒内开始显示数据。

程序必须以管理员权限运行，因为代理需要在内核层级
拦截网络流量（使用 WinDivert 驱动）。


系统要求
--------
- Windows 10 或 11，64 位。
- Microsoft Edge WebView2 运行时（Win11 自带；如缺失可免费下载：
  https://developer.microsoft.com/microsoft-edge/webview2/ ）


隐私说明  （请务必阅读）
------------------------
Setup.bat 会将 mitmproxy 的证书颁发机构（CA）证书安装到
Windows 的受信任根证书库中。这是代理解密游戏 HTTPS
WebSocket 流量的必要步骤。

当代理运行时，持有该 CA 私钥的程序可以拦截你的其他
HTTPS 流量。该私钥保存在你本机的
  %USERPROFILE%\.mitmproxy\
文件夹中，是在你自己的电脑上本地生成的——不会与
发送此 .exe 的人共享。

请仅接受信任的人发送的此类软件。


卸载方法
--------
1. 删除受信任的 CA：
   certutil -delstore Root mitmproxy
2. 删除 Defender 排除项（以管理员身份运行 PowerShell）：
   Remove-MpPreference -ExclusionPath "<此文件夹的路径>"
3. 删除此文件夹。
4. 可选：删除 %USERPROFILE%\.mitmproxy\ 文件夹以移除
   生成的证书文件。


常见问题
--------
- 窗口已打开但计数器始终不更新：
    代理未在拦截流量。常见原因：
      a) 未以管理员权限启动 .exe —— 请使用 Run.bat。
      b) 证书未被信任 —— 重新运行 Setup.bat。
      c) 杀毒软件拦截了 WinDivert —— 请添加排除项，
         或临时关闭实时防护。

- 启动时提示 "Windows 无法访问指定设备"：
    Defender 删除了 .exe。请从隔离区还原 .exe 后
    重新运行 Setup.bat（其中的 Defender 排除项可以
    防止再次发生）。

- 安装后游戏无法进入对战：
    可能是证书信任配置有误。请重新运行 Setup.bat。
    如果仍无法使用，请先按上述方法卸载，然后重新安装。
